1. Overview
This project plan describes Team Smart Expense Tracking’s approach to developing a web-based 
application that enables users to record, categorize, and analyze their daily financial transactions. 
It includes the project’s deliverables, scope, requirements, milestones, communication strategy, 
and risk management plan. 
The system will be implemented using Java for backend logic, MySQL for the database, and 
HTML, CSS, and JavaScript for the frontend. The completed product will allow users to securely 
enter transactions, view summaries, and visualize their spending habits through intuitive charts 
and graphs.
2. Project Deliverables
The Smart Expense Tracking Application will include:
*	A secure login and authentication system.
*	A responsive web interface for entering and managing expenses.
*	Categorization features for tracking spending types (food, transportation, utilities, etc..).
*	Visual analytics such as charts, summaries, and reports.
*	Technical documentation and a final presentation.
The deliverables will be shared via a GitHub repository, accompanied by a live demonstration 
and documentation packet detailing architecture, code structure, and testing procedures.
3. Project Scope
In Scope
*	Expense entry, editing, and categorization.
*	Secure user authentication and role-based access.
*	Expense summaries and visual analytics.
*	Administrative dashboard for user management.
Out of Scope
*	Mobile application version.
*	Integration with external banking APIs.
*	Predictive analytics or AI-based spending forecasts.
*	Cloud synchronization across devices.
This scope ensures focus on delivering a functional, high-quality prototype within the semester 
timeline.

5. Requirements
Business Requirements
*	Provide a simple and secure interface for managing daily expenses.
*	Enable users to track, categorize, and analyze spending trends.
*	Support data visualization through bar and pie charts.
Functional Requirements
*	User login/logout authentication.
*	Expense entry with category selection and date.
*	Expense list view and statistical summaries.
*	Exportable summary reports (CSV / PDF format).
Technical Requirements
*	Operating System: Windows, macOS, or Linux (compatible with Java 17+).
*	Software: IntelliJ IDEA / VS Code, MySQL Workbench.
*	Language Stack: Java 17+, HTML, CSS, JavaScript.
*	Version Control: GitHub repositories.



6. Case Scenario: User Walkthrough
A user logs into the Smart Expense Tracking Application for the first time.
1.	The Welcome Screen prompts for login or account registration.
2.	After logging in, the user accesses the Dashboard displaying recent expenses and a “+ 
Add Expense” button.
3.	Selecting Add Expense opens a form for entering the amount, category, and description.
4.	Upon saving, the record appears in the transaction table with color-coded categories.
5.	The user clicks View Report to see a pie chart of spending by category for the month.
6.	Any incorrect entries can be edited or deleted from the dashboard.
7.	When done, the user logs out; all data remain stored in the secure MySQL database.
Error-handling scenarios include missing required fields, invalid input values, or incorrect login 
attempts.

9. Risk Management
Common risks include schedule delays, integration conflicts, and technical misconfigurations. 
Mitigation strategies are as follows:
*	Schedule Delays: Adopt incremental sprints, assign clear task ownership, and monitor 
progress through GitHub Projects.
*	Integration Issues: Begin early backend-frontend testing and maintain standardized 
APIs.
*	Communication Gaps: Daily updates through Discord, weekly retrospectives.
*	Uneven Workload: Rotate tasks and redistribute assignments as needed.
*	Database Errors: Maintain shared documentation, use backups, and perform regular unit 
testing.
Proactive communication and transparent reporting will minimize these risks.
10. Conclusion
The Smart Expense Tracking Application demonstrates the team’s collaborative ability to design 
and implement a functional, secure, and user-oriented financial tool. The structured timeline, 
defined responsibilities, and risk-management strategies ensure a successful, on-time completion. 
Through consistent collaboration, testing, and documentation, this project will provide a 
professional prototype suitable for demonstration to stakeholders and potential users.
